# SecuSnap: Network Security Plan for a Marketing Agency

**Project Type:** Academic Project  
**Role:** Network Technician / IT Support  
**Simulation Tool:** Cisco Packet Tracer

## Overview

SecuSnap is an academic project focused on designing a network security plan for a marketing agency. It demonstrates the application of networking and security concepts through a simulated network environment using Cisco Packet Tracer.

The project focuses on organizing network devices and controlling network communication through VLAN segmentation, routing, and access control.

## Project Objectives

- Design a structured network security plan for a marketing agency.
- Apply VLAN segmentation to organize network devices.
- Implement routing for network communication.
- Apply access control to help manage network access.
- Demonstrate practical networking and security concepts using Cisco Packet Tracer.

## My Role

**Network Technician / IT Support**

My role focused on the networking aspects of the project, including:
